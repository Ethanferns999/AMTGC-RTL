# Adaptive Multi-Junction Traffic Grid Controller (AMTGC)

## Overview

The Adaptive Multi-Junction Traffic Grid Controller (AMTGC) is a parameterized Verilog RTL project developed as part of the Elevance Skills RTL Design Internship.

The system models two coordinated 4-way traffic junctions with adaptive traffic control, pedestrian arbitration, emergency override, and green-wave synchronization.

The objective of this project is to demonstrate professional RTL design practices, modular architecture, parameterized hardware design, verification methodology, and documentation suitable for semiconductor industry standards.

---

## Features

- Two coordinated 4-way traffic junctions
- Parameterized Moore FSM design
- Generic reusable timer module
- Shared pedestrian arbiter
- Emergency override support
- Green-wave synchronization
- Adaptive traffic timing
- Self-checking verification environment
- Modular RTL architecture
